What it is for

Retrieve news published inside an exact date window, so you can read what was available at the time without later coverage leaking in. Both dates are inclusive, and the end date is the cutoff: nothing published after it is returned.

That reduces look-ahead bias, which means using information that was not available when a historical decision was made. It does not remove it. Archives are incomplete, a publication timestamp is not the moment information became tradable, articles are edited after publication, and a language model may already know what happened next from its training. A serious backtest applies the cutoff to every input, not only the news.

This tool retrieves and exports. It does not calculate returns, simulate trades, or summarize articles. There is no language model call anywhere in the code.

The browser page runs in three steps: build the search, review the archive, then compare it with what people searched for over the same dates.

Sources and credentials

Six sources are queried in parallel, then normalized into one article shape and deduplicated. A source with no configured key is shown dimmed in the browser and cannot be selected.

Source Needs Worth knowing
GDELT Nothing Rate limited to roughly one request every 5 seconds
MediaCloud MEDIACLOUD_API_KEY Searches the collections named in [sources]
ACLED OAuth login, then a bearer token Conflict and protest events; tokens last 24 hours
The New York Times NYT_API_KEY Publisher archive with consistent article details
The Guardian GUARDIAN_API_KEY Publisher archive with consistent article details
NewsAPI NEWSAPI_API_KEY The free plan reaches back about one month only

More sources improve coverage but do not remove selection, geographic, editorial, survivorship, or language bias. Every normalized article keeps its source name so later work can measure or filter those differences.

Reading coverage honestly

A search across six sources where four failed returns the same article count as a search where four simply had nothing matching. Those mean very different things, so failures are always stated.

  • Every response carries source_reports: one entry per requested source, with how many articles it returned and any error.
  • The browser shows one status chip per source under the result summary.
  • The command line prints a warning naming each failed source, inline for the table and on the error stream for JSON, JSON Lines, and file exports, so the data stays parseable.
  • The message repeats what the provider said, with configured credentials removed from that text first.

Before trusting a result, check source_reports. A count alone cannot tell you whether the window was covered.

Commands for agents

Inside a checkout of this project, prefix every command with uv run. With the package installed elsewhere, call it directly. The examples below omit the prefix.

Sign in

Every route that returns news needs an account. The command line sends it as an HTTP Basic header on each request. 

export NEWS_SERVER_URL="https://news.example.com"
export UI_USERNAME="the-account-name"
export UI_PASSWORD="the-account-password"

curl -s "$NEWS_SERVER_URL/healthz"

The health route needs no account and answers {"status":"ok"}. The command line reads .env from the current working directory, so run it from the project folder or set NEWS_DATA_DIR.

The password travels in plain text. Use it only over HTTPS or a private network, never a plain-HTTP public port. Never write it into a file, a commit, or visible output.

Retrieve articles

# readable table
news-search "inflation" -s 2025-01-01 -e 2025-03-01

# structured, for a model or a script
news-search "central bank policy" \
  --start 2026-01-01 --end 2026-01-31 \
  --english --format json --quiet

# one compact article per line
news-search "central bank" -s 2025-01-01 -e 2025-01-31 --format jsonl

# every available page, combined
news-search "inflation" -s 2025-01-01 -e 2025-03-01 --all-pages --format json

# write a file instead of printing
news-search "inflation" -s 2025-01-01 -e 2025-03-01 --export csv -o out.csv

Search attention

# attention over the same window as a search
news-trends "central bank" -s 2015-01-01 -e 2015-06-30 --geo US

# only what was knowable on one decision date
news-trends "bitcoin" -s 2017-01-01 -e 2017-09-15 --as-of 2017-01-31

# machine-readable
news-trends "inflation, recession" -s 2020-01-01 -e 2020-06-30 --format json

news-trends calls Google directly rather than this server, so it needs no account and takes no --server.

Rules for an agent

  • Retrieval is the deliverable. Do not summarize the news unless the user asks for a summary.
  • Never invent a hostname, an account name, or a password. Ask for what you were not given.
  • Read source_reports before reporting coverage, and say which sources answered.
  • Do not claim what an article says beyond the title and summary actually returned. Full bodies are usually not included.

.agents/skills/news-cli/SKILL.md in the repository is a skill file to copy into an agent's own skills folder. It carries these same rules in the form an agent loads directly.

curl -u "$UI_USERNAME:$UI_PASSWORD" \
  "$NEWS_SERVER_URL/api/search?q=inflation&start=2025-01-01&end=2025-03-01"

A refused request explains itself: a reversed window answers with the sentence naming the problem, and an unknown source name answers with the list of valid names. The full schema is in docs/reference/openapi.json.

Search attention

Articles say what was published. Search attention says what people were looking for, including subjects the press had not covered yet. The third section of the search page draws it for the query and window already in the form.

Two facts decide whether the numbers mean anything. The value is a relative index from 0 to 100, never a count of searches. And Google scales every value to the peak of the whole window requested, so a series fetched for six months tells its first week about a spike that had not happened yet.

Set a decision date to drop the later points and rescale to the highest value up to that date. Without it, an attention series carries exactly the look-ahead bias the rest of this tool exists to avoid.

Known limits

  • Google Trends rate limits aggressively. Raise seconds_between_requests in config.toml if refusals are frequent.
  • GDELT allows roughly one request every 5 seconds and refuses the rest.
  • The NewsAPI free plan cannot serve windows older than about a month, whatever dates are requested.
  • ACLED bearer tokens expire after 24 hours and must be regenerated.
  • Duplicate removal currently matches near-identical titles and addresses. Two outlets rewriting the same wire story are often kept as separate articles.
