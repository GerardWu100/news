Purpose

Retrieve news published inside an exact date window. Both dates are inclusive; nothing published after the end date is returned.

This reduces look-ahead bias: using information that was not available when a historical decision was made. It cannot remove the risk. Archives can be incomplete, publication time may differ from trading time, articles can be edited, and a language model may know later events from its training. A serious backtest applies the cutoff to every input.

This tool retrieves and exports. It does not calculate returns, simulate trades, or summarize articles. It makes no language-model calls.

The browser workflow is simple: build the search, review the archive, then compare it with search attention from the same dates.

Sources and credentials

Six providers run in parallel. Their records are converted to one article shape and deduplicated. A provider without a configured key is dimmed and cannot be selected.

SourceNeedsWorth knowing
GDELTNothingAbout one request every 5 seconds
MediaCloudMEDIACLOUD_API_KEYUses collections from [sources]
ACLEDOAuth login and bearer tokenConflict and protest events; tokens last 24 hours
The New York TimesNYT_API_KEYPublisher archive with consistent article details
The GuardianGUARDIAN_API_KEYPublisher archive with consistent article details
NewsAPINEWSAPI_API_KEYFree plan reaches back about one month

More providers improve coverage but do not remove geographic, editorial, selection, survivorship, or language bias. Each article keeps its source name so later work can measure those differences.

Coverage reports

Four failed providers and four providers with no matching articles can produce the same total. They do not mean the same thing, so failures are always reported.

  • Every response has source_reports, with one count and any error per requested source.
  • The browser shows one status chip per source.
  • The CLI warns about failures without corrupting JSON, JSON Lines, or exported files.
  • Provider messages are kept after configured credentials are removed.

Check source_reports before trusting a result. A count alone does not show whether the whole window was covered.

Commands for agents

In a checkout, prefix commands with uv run. The examples omit that prefix. An installed package can be called directly.

Sign in

News routes need an account. The CLI sends it as an HTTP Basic header on every request. 

export NEWS_SERVER_URL="https://news.example.com"
export UI_USERNAME="the-account-name"
export UI_PASSWORD="the-account-password"

curl -s "$NEWS_SERVER_URL/healthz"

/healthz needs no account and returns {"status":"ok"}. The CLI reads .env from the current directory, so run it from the project folder or set NEWS_DATA_DIR.

The password travels in plain text. Use HTTPS or a private network. Never expose a plain-HTTP public port or write the password to a file, commit, or visible output.

Retrieve articles

# readable table
news-search "inflation" -s 2025-01-01 -e 2025-03-01

# structured output
news-search "central bank policy" \
  --start 2026-01-01 --end 2026-01-31 \
  --english --format json --quiet

# one article per line
news-search "central bank" -s 2025-01-01 -e 2025-01-31 --format jsonl

# combine every page
news-search "inflation" -s 2025-01-01 -e 2025-03-01 --all-pages --format json

# write a CSV file
news-search "inflation" -s 2025-01-01 -e 2025-03-01 --export csv -o out.csv

Search attention

# same window as an article search
news-trends "central bank" -s 2015-01-01 -e 2015-06-30 --geo US

# information available on one decision date
news-trends "bitcoin" -s 2017-01-01 -e 2017-09-15 --as-of 2017-01-31

# machine-readable output
news-trends "inflation, recession" -s 2020-01-01 -e 2020-06-30 --format json

news-trends calls Google directly. It needs no account and accepts no --server.

Rules for an agent

  • Return retrieved data; summarize only when asked.
  • Never invent a hostname, account, or password.
  • Read source_reports and name the sources that answered.
  • Do not claim more than the returned title and summary support; full bodies are usually absent.

Copy .agents/skills/news-cli/SKILL.md into the agent's skills folder to load these rules directly.

  "$NEWS_SERVER_URL/api/search?q=inflation&start=2025-01-01&end=2025-03-01"

Rejected requests explain the problem, such as a reversed date window or an unknown source. The full schema is in docs/reference/openapi.json.

Search attention

Articles show what was published. Search attention shows what people searched for, including subjects the press had not covered yet. The browser draws it for the active query and window.

The values are a relative index from 0 to 100, not search counts. Google scales each request to its own peak, so a long-window series can let a later spike influence its early values.

Set a decision date to drop later points and rescale the remaining series. Otherwise the attention data contains look-ahead bias.

Known limits

  • Google Trends rate-limits aggressively. Increase seconds_between_requests when refusals are frequent.
  • GDELT allows roughly one request every 5 seconds.
  • The NewsAPI free plan reaches back only about one month.
  • ACLED bearer tokens expire after 24 hours.
  • Deduplication catches near-identical titles and addresses, but often keeps rewritten wire stories.
